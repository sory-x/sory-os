# @openai/sory-responses-api-proxy

<p align="center"><code>npm i -g @openai/sory-responses-api-proxy</code> to install <code>sory-responses-api-proxy</code></p>

This package distributes the prebuilt [sory Responses API proxy binary](https://github.com/openai/sory/tree/main/sory-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/sory-responses-api-proxy.js --help
```

Refer to [`sory-rs/responses-api-proxy/README.md`](https://github.com/openai/sory/blob/main/sory-rs/responses-api-proxy/README.md) for detailed documentation.
